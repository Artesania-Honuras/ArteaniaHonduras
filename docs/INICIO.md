## Reglas en tres líneas

1. **Registro:** todo cambio → `C-NN`; todo experimento → `E-NN`; toda sesión → Log. Todo se
   commitea y se sube en la misma sesión.
2. **Cambios:** sin medición reproducible, registro y despliegue verificado, no hay cambio.
3. **Estado:** "¿está todo al 100%?" se responde con la tabla de `npm run estado`, nunca con una
   opinión.
